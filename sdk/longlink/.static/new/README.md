## Getting Started

```bash
uv sync
uv run longlink migrate
uv run longlink dev
```

Commit the generated `uv.lock` before enabling CI or creating a release.

<br />

## Migrate changes

```bash
uv run longlink migrate
```

<br />

## Release

```bash
git tag v0.1.0
git push origin v0.1.0
gh release create v0.1.0 --generate-notes
```
